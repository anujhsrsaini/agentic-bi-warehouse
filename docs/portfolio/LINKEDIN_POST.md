# LinkedIn post draft

I built a local business analytics assistant as a portfolio project to explore a practical question: how can someone ask about business data and see how the answer was calculated?

The guided demo uses historical e-commerce data. It shows sales and delivery metrics with their definitions, source tables, caveats, and SQL. It also asks for clarification when “revenue” is ambiguous and rejects an example unsafe query.

The project uses Python, DuckDB, Parquet, a YAML semantic layer, and SQLGlot validation. The guided examples run locally without an AI model after installation. In a client engagement, the questions, definitions, data integration, and access controls would be tailored to the business.

Project: https://github.com/anujhsrsaini/agentic-bi-warehouse
